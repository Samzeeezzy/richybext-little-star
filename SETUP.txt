RICHYBEXT LITTLE STAR — CLASSIC DESIGN + LIVE REGISTRATION

This package keeps the original classic Richybext Little Star design and connects only the registration system to Supabase.

1. Supabase database and storage: use the supplied supabase-schema.sql and create the public bucket contestant-photos.
2. The frontend uses ONLY the Supabase Publishable Key. Never put the secret/service_role key in GitHub.
3. Upload/replace these three files in the GitHub repository:
   - index.html
   - style.css
   - script.js
4. GitHub Pages should continue using the main branch.
5. Registration submissions are saved as pending in public.registrations and photos are uploaded under pending/.
6. Approved contestants can appear automatically in the existing classic contestant cards.

The publishable key is already configured in script.js.
